Networking Concepts

This page explains how networking makes our website work by connecting various concepts to our actual deployment on GitHub Pages.

DNS (Domain Name System)

DNS is responsible for translating human-readable domain names into IP addresses. When you visit csc6220-project-1.github.io, your browser queries a DNS server to find the corresponding IP address.

In our case, the domain is a subdomain of github.io. GitHub uses A records (for IPv4) and AAAA records (for IPv6) or CNAME records to direct traffic to their content delivery network (CDN) servers.

Protocols

Our website is served over HTTPS (Hypertext Transfer Protocol Secure), which uses TLS (Transport Layer Security) to encrypt communication between your browser and the server.

Status Codes

When a page is successfully loaded, the server returns a 200 OK status code. If a page is not found, it returns a 404 Not Found.
